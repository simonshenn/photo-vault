# Photo Vault

Private photo site for one user, built as an AI-native SDLC learning project.
Program docs live in `docs/program/`. The full project context gets added in
Step 3b.

## Planning

- Milestone dates, scope, and reflections are Simon's decisions. Claude proposes
  them with reasoning and assumptions, and writes them after Simon approves or
  edits.
- Label every proposed date or estimate "Proposed" with its basis: task
  breakdown, weekly hours, dependencies. Only dates with a stated basis go into
  docs or GitHub.
- Break each milestone into 3 to 6 issues. Give each issue an hour estimate and
  a role, and roll the estimates up into the milestone target date.
- Capacity: 4 to 6 hours per week, one step per week. Weekly status report on
  Fridays.
- Send each edit, commit, and GitHub change as its own tool call so Simon can
  approve each one.
